AI 복습 자료 관리 PWA 사용법

1. 이 폴더 전체를 HTTPS가 되는 곳에 업로드하세요.
   추천:
   - GitHub Pages
   - Netlify
   - Vercel
   - Replit

2. 아이패드 Safari에서 업로드한 주소를 엽니다.

3. 공유 버튼을 누른 뒤 '홈 화면에 추가'를 선택합니다.

4. 홈화면 아이콘으로 실행하면 Safari 주소창 없이 앱처럼 실행됩니다.

포함 기능:
- PWA 홈화면 설치
- 전체화면 standalone 실행
- 아이콘 표시
- Service Worker 캐시
- localStorage 저장 유지
- 실제 OCR: Tesseract.js 사용
- 과목 자동 분류
- 에빙하우스 복습 주기: 1일, 3일, 7일, 14일, 30일
- 오늘의 복습 파일 자동 생성
- 앱 실행 중 알림 기능

중요 제한:
- 실제 OCR은 인터넷 연결이 필요합니다.
- 아이패드에서 '앱을 완전히 닫아도 정해진 시각에 오는 진짜 푸시알림'은 서버 기반 Web Push가 필요합니다.
- 이 파일은 서버 없는 버전이므로 앱이 실행 중일 때 알림이 가장 안정적으로 작동합니다.
