AI 복습 자료 관리 PWA - 압축 저장 + 전체화면 뷰어 + 펜 기능

수정 내용:
1. 이미지 저장 전 자동 압축
   - 긴 축 1200px 기준으로 축소
   - JPEG 품질 0.62로 저장
   - localStorage 용량 부족 문제 완화

2. 저장된 이미지 전체화면 보기
   - 카드 이미지 클릭
   - 전체화면 뷰어 열림
   - 확대/축소 버튼 제공
   - 손가락 두 개 pinch zoom 지원
   - 드래그 이동 지원

3. 펜 기능
   - 펜 켜기/끄기
   - 이미지 위에 빨간색 표시
   - 되돌리기
   - 지우기
   - 펜 저장

주의:
- 펜 표시도 localStorage에 저장되므로 너무 많이 그리면 저장 공간을 다시 많이 사용할 수 있습니다.
- 더 큰 저장공간이 필요하면 IndexedDB 버전으로 바꾸는 것이 좋습니다.
- GitHub Pages에 반영한 뒤 iPad에서 예전 화면이 보이면 홈화면 앱 삭제 후 Safari에서 ?v=5를 붙여 접속하고 다시 홈화면에 추가하세요.
